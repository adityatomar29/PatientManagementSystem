# Patient Management System 🏥

Patient Management System is a backend-based healthcare application developed using FastAPI and Pydantic. The project manages patient records efficiently and also includes a Machine Learning-based Insurance Predictor feature built and tested in Google Colab.

🛠️ Tech Stack
- Python
- FastAPI
- Pydantic
- Machine Learning
- Pandas
- NumPy


📌 Features
- Patient record management system
- REST API development using FastAPI
- Data validation using Pydantic
- CRUD operations for patient data
- Insurance cost prediction using ML
- JSON-based API responses
- Fast and scalable backend architecture



▶️ Run the FastAPI Server:
- uvicorn main:app --reload

- The API server will start locally at:

http://127.0.0.1:8000

📖 API Documentation

- FastAPI automatically generates interactive API documentation.

- Swagger UI:
http://127.0.0.1:8000/docs
